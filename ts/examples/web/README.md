# trackplan web example

A minimal TypeScript project that uses code generated by trackplan. It runs
in Node so it needs no bundler; the same generated file works in a browser or
React Native app.

- [`tracking_plan.yaml`](tracking_plan.yaml): the plan.
- `src/analytics/analytics.ts`: the generated code (run `npm run generate`).
- [`src/main.ts`](src/main.ts): tracks two events with
  `DebugAnalyticsAdapter`, `RecordingAnalyticsAdapter` and an optional
  beacon adapter for your own HTTPS collector.

The example installs trackplan from this repository, so build the package
first (`npm ci && npm run build` in `ts/`). Then:

```sh
npm install
npm run generate   # writes src/analytics/analytics.ts
npm run check      # what CI runs
npm run build
npm start
```
