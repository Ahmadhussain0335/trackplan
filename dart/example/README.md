# trackplan example

A small Flutter app that uses code generated by trackplan.

- [`tracking_plan.yaml`](tracking_plan.yaml): the plan with two events and
  one enum.
- [`lib/analytics/analytics.g.dart`](lib/analytics/analytics.g.dart): the
  generated code. Do not edit it by hand.
- [`lib/main.dart`](lib/main.dart): screens that call
  `analytics.productViewed(...)` and `analytics.checkoutCompleted(...)`.
- [`test/`](test/): unit and widget tests using `RecordingAnalyticsAdapter`.
- [`TRACKING_PLAN.md`](TRACKING_PLAN.md): the generated event catalog.

An excerpt of the plan:

```yaml
events:
  checkout_completed:
    description: User finished payment successfully.
    params:
      order_id:
        type: string
      total:
        type: double
        min: 0
      payment_method:
        type: enum
        enum: payment_method
      coupon_code:
        type: string
        required: false
        max_length: 32
```

The call in the app:

```dart
analytics.checkoutCompleted(
  orderId: 'order-${product.id}',
  total: product.price,
  paymentMethod: PaymentMethod.card,
);
```

## Run it

```sh
flutter pub get
dart run trackplan generate   # regenerate after editing tracking_plan.yaml
dart run trackplan check      # what CI runs
flutter test
```

The example has no platform folders, to keep the package small. To run it on
a device, copy the folder and add them in the copy:

```sh
flutter create . --platforms=android,ios
flutter run
```

For Firebase, PostHog and custom adapters, see the
[package README](https://pub.dev/packages/trackplan#adapters).
